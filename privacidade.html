Privacidade no catálogo de pedidos

Este catálogo funciona diretamente no navegador. O carrinho e as escolhas de produtos podem ser armazenados localmente no seu dispositivo para facilitar a navegação.

Dados do pedido

Nome, telefone, endereço, forma de pagamento e observações são usados apenas para montar a mensagem do pedido no seu dispositivo. O site não possui banco de dados próprio para armazenar esses campos.

Envio pelo WhatsApp

Ao escolher “Enviar pelo WhatsApp”, você é direcionado ao WhatsApp com a mensagem do pedido pronta. O envio só ocorre quando você confirma a mensagem no próprio WhatsApp. A partir desse momento, o tratamento dos dados também está sujeito aos termos e políticas do WhatsApp/Meta.

Armazenamento local

Itens do carrinho e personalizações podem permanecer salvos no navegador até que sejam removidos, o carrinho seja limpo ou os dados do site sejam apagados no dispositivo.

Evite inserir informações sensíveis desnecessárias no campo de observações.
