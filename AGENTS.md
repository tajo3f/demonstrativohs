# AGENTS

Antes de alterar este projeto:
1. Preserve o visual de aplicativo mobile-first.
2. Não adicione frameworks pesados sem necessidade.
3. Não invente preços, pesos, estoque, validade ou alegações comerciais.
4. Preserve o carrinho no `localStorage`.
5. Mantenha o PWA e a instalação funcionais.
6. Execute `npm run check` antes de entregar.
7. Mudanças estruturais devem ser registradas no `CHANGELOG.md`.
