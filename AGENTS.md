# AGENTS

Antes de alterar este projeto:
1. Preserve o visual de aplicativo mobile-first.
2. Não adicione frameworks pesados sem necessidade.
3. Não invente preço, peso, estoque, validade ou alegações.
4. Preserve o carrinho em LocalStorage.
5. Mantenha PWA e instalação funcional.
6. Rode `npm run check` antes de entregar.
7. Mudanças estruturais devem registrar contexto no CHANGELOG.md.
