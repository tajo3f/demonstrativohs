## Salada de Frutas
O cliente pode selecionar as frutas desejadas. A seleção é salva no navegador junto ao carrinho e aparece no resumo do pedido. A lista inicial de frutas fica em `FRUIT_OPTIONS`, em `assets/js/app.js`, para ser ajustada conforme a disponibilidade oficial da HS.

## Organização do catálogo
O catálogo permanece organizado por linhas comerciais:
- Todos
- Processados
- Saladas
- Kits

## Executar
Abra `index.html` em servidor local ou publique na Vercel. Para testar:

```bash
npm run check
```
