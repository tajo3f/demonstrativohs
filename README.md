# HS Hortigranjeiro Schulz — Catálogo/Pedidos

Versão final oficial do catálogo da linha de produtos processados e higienizados da HS.

## Conteúdo
- 40 produtos únicos com fotos fornecidas pela HS.
- Catálogo responsivo para celular, tablet e desktop.
- Carrinho com armazenamento local.
- Pedido formatado e encaminhado ao WhatsApp oficial **+55 27 99908-7648**.
- Salada de frutas 250 g por R$ 12,49: escolha de 1 a 3 frutas + opcionais de R$ 3,49 cada.
- Seleta de legumes 500 g por R$ 7,99: opção sem milho ou com 80 g de milho em conserva por +R$ 3,49.
- PWA instalável e funcionamento offline do shell/cache.

## Testes
```bash
npm test
npm run check
```

O arquivo `tests/browser_smoke.py` contém um teste de navegador para ambientes que permitam Chromium local.

## Deploy
O projeto é estático. Pode ser publicado no Vercel apontando a raiz do repositório. O `vercel.json` já inclui cabeçalhos de segurança e cache.

## Observação
Disponibilidade e itens sazonais continuam sujeitos ao estoque e à confirmação comercial da HS.
